# Buku Uang

Pencatat uang pribadi berbentuk satu halaman web, dioptimalkan untuk iPhone.

## Fitur
- Catat uang keluar, masuk, dan pindah saldo antar akun (Cash, ShopeePay, DANA, dll.)
- Akun "titip" (uang di orang lain) dipisah dari uang siap pakai
- Strip tanggal per minggu, statistik pengeluaran 7 hari, dan rincian per kategori
- Daftar hutang/cicilan dengan tombol Bayar (otomatis tercatat sebagai pengeluaran)
- Mode terang dan gelap mengikuti pengaturan perangkat

## Penyimpanan
- Saat dibuka sebagai artifact di claude.ai, data tersimpan di akun Claude dan fitur **Foto struk** aktif.
- Saat dibuka langsung dari file atau hosting lain, data disimpan di `localStorage` browser (hanya di perangkat itu) dan Foto struk disembunyikan.

## Buka cepat di iPhone (Back Tap)
1. App Shortcuts → buat shortcut baru → aksi **Open URLs** → isi link halaman ini.
2. Settings → Accessibility → Touch → Back Tap → Double Tap → pilih shortcut tadi.
